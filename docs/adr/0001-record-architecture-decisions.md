# 1. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-28

## Context

Decisions get made once and questioned many times. Without a record, the reason for a choice is lost, and later changes either repeat old mistakes or undo good choices by accident.

## Decision

Record each significant decision as a short Architecture Decision Record (ADR) in `docs/adr`, numbered in order: context, decision, consequences. An ADR is not edited after it is accepted; a later ADR supersedes it.

## Consequences

- A reviewer or new contributor can see *why* the code looks the way it does.
- Writing one takes ten minutes, so it only happens for decisions that are costly to reverse.
